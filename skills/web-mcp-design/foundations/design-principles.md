# Design Principles

Output path: `foundations/design-principles.md`

## Active Principles

| Principle | Operational rule | System layer controlled |
| --- | --- | --- |
| Make structure inspectable | Show meaningful paths, nodes, measurements, boundaries, and state labels; remove geometry that cannot explain a relationship. | visual DNA, diagrams, progress, focus, data display |
| Align the useful; rupture the expressive | Keep reading, controls, and state stable on-grid. Permit one nonessential display anchor to crop, rotate, invert, or cross columns. | spatial grammar, typography, applications |
| Use polarity before colour | Communicate hierarchy and state through black/white inversion, lightness, line, fill, pattern, and copy. | palette, accessibility, states |
| Alternate silence and signal | Keep most of the canvas quiet; concentrate texture or data density in one bounded region when evidence or activity requires it. | surface, imagery, density, motion |
| Let scale do the branding | Create recognition through micro/macro typography, disproportion, and edge behavior using JetBrains Mono. | typography, brand expression, campaigns |
| Settle after consequence | Motion traces causality briefly, then stops. Completion is a durable state, not a celebration. | motion, interaction, feedback |

## Emotional Register

- Governing register: controlled launch tension—cold, exact, and poised between stillness and decisive state change.
- Supporting registers: editorial confidence, measured utility, industrial tactility, and quiet spectacle.
- Avoid playful futurism, cyberpunk, warm nostalgia, conversational friendliness, luxury gloss, bureaucratic density, and generic developer-tool chrome.

## The Establishment

- Train users to read open/closed nodes as state, paths as causality, inversion as bounded emphasis, and micro labels as operational evidence.
- Repeat at least two grammar cues in every major artifact, but never force all cues into one component.
- Palette and spatial foundations establish the field; actions, progress, navigation, status, and data components enforce state; inspect/reveal/signal patterns connect them.

## The Subversion

- One expressive anchor may break the grid through scale, crop, 90-degree rotation, a single 45-degree diagonal, or local inversion.
- Trigger only for a primary identity moment, section transition, selected object, confirmed operation, or major data reveal.
- The largest impact belongs to the first meaningful view or the moment an operation resolves.
- Essential copy, controls, focus order, and status remain on-grid. Only one break is active per viewport, it uses neutral colour, and the following region returns to quiet alignment.

## Establishment To Subversion Ratio

- Establish two stable alignments or repeated nodes before breaking one.
- Limit to one rupture per viewport and no more than one dense signal region per composition.
- Recover within the same component or next scroll region by restoring grid alignment, normal orientation, and a large quiet field.

## Cross-Domain Coherence

| Domain | Principle expression |
| --- | --- |
| Palette | binary polarity with graphite hierarchy; state remains redundantly encoded |
| Typography | one mono family spanning precise microcopy and monumental crops |
| Space | rigorous grid for function plus one bounded overflow for expression |
| Motion | node-path-node causality, stepped inversion, immediate reduced-motion state |
| Surface | matte neutral planes with restrained grain and bounded one-bit raster |
| Interaction | sparse, persistent, factual feedback with explicit recovery |

## Anti-Patterns

- Calling arbitrary decoration “inspectable”; adding fake measurements; using overflow on essential content; making every region high contrast; treating monochrome as permission for inaccessible grey; flooding layouts with nodes; using halftone as a wallpaper; or adding motion where no state or spatial relationship changes.
- Avoid generic principles such as “simple,” “modern,” or “bold” unless translated into a measurable rule above.

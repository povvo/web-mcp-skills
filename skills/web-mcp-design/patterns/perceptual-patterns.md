# Perceptual Patterns

Output path: `patterns/perceptual-patterns.md`

## Perceptual Pattern Inventory

| Pattern | Recognition cue | Emotional effect | System layer |
| --- | --- | --- | --- |
| Polarity Field | one dominant near-black/off-white region with a bounded inverse | controlled decisiveness | palette, surface, selection |
| Micro / Monument | 11-13px measured labels against a cropped 4-18rem JetBrains Mono anchor | editorial scale tension | typography, brand, layout |
| Inspectable Path | one-pixel orthogonal/45-degree route with meaningful circular nodes | causality and trust | icons, focus, progress, diagrams |
| Quiet / Signal | large empty field paired with one dense halftone or data region | poised energy without noise | spatial density, imagery, status |
| Measured Edge | real counts, dimensions, timestamps, or state labels aligned to rails/bounds | precision and evidence | data display, captions, wayfinding |
| Matte Reproduction | restrained grain plus crisp foreground geometry | tactile, industrial-editorial finish | surface, media |
| Aligned Rupture | useful content stays on-grid while one nonessential object crops, rotates, or crosses columns | memorable controlled subversion | composition, campaign, hero |
| Settled Consequence | brief node/path response followed by durable still state | confidence rather than celebration | motion, interaction, feedback |

## Pattern Families

- Brand palette is neutral polarity plus graphite recession; there is no signature hue.
- Typography style is the single JetBrains Mono family stretched across a radical scale interval without custom glyph imitation.
- Icon style is schematic and labelled: paths relate, nodes state, frames bound, diagonals transform.
- Imagery becomes truthful monochrome media or original line construction; bounded halftone is the signal treatment.
- Hero, avatar, product, and empty-state media follow their factual role rather than receiving a universal decorative filter.
- Layout Density alternates quiet and signal. At most one dense region and one expressive rupture appear in a major composition.
- Shape language is square with small technical turns and true circular nodes; pills and soft cards are foreign.
- Motion language traces causality once, cuts through inversion, and settles. Reduced motion preserves final geometry.
- Voice and tone are factual, terse, and state-precise; copy never invents technical residue to decorate the frame.

## Hierarchy And Consistency Test

Recognition should survive the removal of the displayed name. A coherent artifact uses at least two cues above, preserves a clear first/second/third reading order, keeps functional content aligned, and leaves a significant quiet region. Consistency means shared grammar, not identical compositions: vary crop, topology, density, inversion, and media while retaining token/state semantics.

## Anti-Patterns

- Using all cues at once; treating every node as branding; fake measurements; halftone wallpaper; giant type that obscures essential text; monochrome with insufficient contrast; random diagonal cuts; multiple overflow anchors; motion as atmosphere; or copying a source mark instead of using the grammar.
- Avoid near-professional inconsistency: one off-grid label, one wrong radius, a disappearing hairline, or a substitute font can undermine the deliberately exact system more than an intentionally sparse feature set.

## Positive Prompt Construction

- Subject: name the real object or abstract relationship. Bind every visual attribute to that object; omit unsupplied actors, products, screens, and data.
- Composition: rigorous off-axis grid, 40-70% quiet field, one dominant anchor, one bounded signal region, and at most one crop/rotation rupture.
- Palette: near-black, paper white, and graphite only. Monochrome means zero intentional hue, not low-saturation blue.
- Light: flat frontal contrast or hard side separation; no glow, fog, bloom, or cinematic colour wash.
- Material: matte screen/paper, crisp plotted geometry, restrained dry grain, coarse one-bit reproduction inside media only.
- Style: instrumented monochrome, editorial precision, inspectable structure, controlled launch tension, tactile reproduction.
- Camera/viewpoint: frontal or slight high-angle documentary view; close enough to inspect decisive evidence; moderate/deep focus.
- Text handling: exact name is “WEB MCP” when required, set in JetBrains Mono, no additional words. Prefer generating the background without text and overlaying live type in layout software/code.

## Positive Prompt Example

Create an original 16:9 identity field on a matte near-black canvas. Reserve the upper-left 60% as quiet space. Place one oversized, partially cropped “WEB MCP” text zone for later live JetBrains Mono typesetting along the lower edge. Add one thin off-white orthogonal path with two purposeful round nodes and a single 45-degree transition. Include one bounded graphite halftone rectangle at the right edge and three small real-content label positions aligned to its frame. Keep geometry crisp, planar, neutral, and source-independent.

## Negative Constraints

- Avoid vague “futuristic,” “AI,” “tech,” “cyber,” “minimal,” or “brutalist” direction unless followed by the concrete facts above.
- Wrong materials: glass, glossy chrome, liquid metal, plastic gradients, soft felt, torn collage, heavy vintage distress.
- Wrong lighting: neon rim light, volumetric fog, bloom, lens flare, coloured shadow, glossy reflection.
- Wrong crop: multiple competing crops, essential object/state removed, centred stock composition, dense edge-to-edge texture.
- Text failures: wrong name, extra words, malformed JetBrains Mono, custom techno glyphs, raster-only essential instructions, unreadable microcopy, fake identifiers.
- Localization failures: text baked into backgrounds, fixed narrow zones, symbolic gestures without labels, decorative numbers mistaken for real content.

## Failure Checks

Reject any result that leaks a known mark/composition, uses product clichés prompted only by the name, introduces hue, lacks quiet space, contains multiple signal regions, makes geometry decorative/unreadable, obscures the subject, fabricates product facts, or cannot be reconstructed with live type and original vector elements.

## Variant Strategy

- Controlled variables: base polarity, crop edge, path topology, node count, halftone cell size, focal subject, aspect ratio, and density state. Change one purposeful variable per variant.
- Fixed invariants: JetBrains Mono text treatment, neutral palette, matte field, one rupture, one signal region, quiet space, original assets, meaningful geometry, and live essential text.
- Runtime generation uses no reference images. If an implementation later supplies rights-cleared product media, use it only as subject truth and lock identity/style constraints separately.
- Compare variants for text correctness, source independence, object binding, exact counts, negative compliance, crop, contrast, texture scale, accessibility alternative, and channel safe zones.
